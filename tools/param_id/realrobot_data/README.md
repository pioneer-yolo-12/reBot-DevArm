# 实机辨识数据与报告

仓库保存分析脚本、Markdown 报告、JSON 诊断结果和图表。本次代码提交没有加入新增的大型 `.jsonl` 采集日志及 `.npz` 原始/派生数组；这些文件仍完整保留在采集电脑本地，既有已跟踪的数据不受影响。

部分报告中的原始文件及数组链接需要在采集电脑打开。`local_arrays_manifest_20261019.json` 记录本次留在本地的新增日志/数组路径、大小及 SHA-256，便于日后单独归档与核对。它不表示文件已经上传到外部数据存储。

离线重算需取得对应原始 NPZ，并安装 NumPy、SciPy；绘图另需 Matplotlib。运行审计不等于物理力矩校验，诊断结果不能直接用作已验证补偿参数。
