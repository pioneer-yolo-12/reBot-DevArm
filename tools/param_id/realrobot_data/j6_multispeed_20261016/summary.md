## 采集

## 物理解释和补偿决定

- 力矩标定仍未完成。因此模型重力 N*m 仅作单独参考，没有从协议力矩中直接相减，拟合惯量不是已确认的 kg·m²。固定姿态下的近似常量重力和零偏可进入 bias，不能声称已完成所有物理项的绝对标定。
- 0.12 / 0.20 / 0.28 秒求导窗口下，位置周期约 0.04477–0.04478 rad，独立验证均支持位置项；但黏性系数约 0.0005 / 0.0363 / 0.0963，惯性系数也变化。位置纹波结论稳健，Fc/Fv 和惯量的物理解释尚不充分。
- 本分支只比较单轴集总模型。完整六轴耦合、传感误差与载荷变化仍未被辨识；不可把该模型当作完整逆动力学模型。
- 决定：将位置周期项与速度摩擦分开研究；先核查驱动器/编码器与力矩标定，再设计独立的限幅干预实验。**本轮不自动启用补偿，不把该诊断模型交给在线摩擦补偿入口。** 原 Method D 门限不变。
