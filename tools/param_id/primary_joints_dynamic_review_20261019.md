# 四轴配对动态模型离线分析

## 本轮完成的工作

增加 `friction_id/paired_dynamic.py` 与 `analyze_friction.py` 的 `paired-dynamic-fit` / `paired-dynamic-validate` 命令。仅读取现有 NPZ，没有打开 CAN、使能电机或加载新补偿。原 Method D 的匀速门限未变。

使用同位置正反向力矩半差 D、半和 S；在共同角区间每 .002 rad 配对，检查其余五轴差≤.003 rad、位置插值间隔≤.004 rad及局部时间跨度≤40 ms，禁止外推。导数窗口内陈旧反馈、坏时间戳、故障等仍拒绝。每次往返等权拟合，不能以大量相邻位置 bin 代替重复试验。

公式（加减号表示实际运动方向，所有量插值至同一个实际角度）：

```text
D = (τ+ − τ−)/2
  ≈ Fc·[tanh(v+/.02) − tanh(v−/.02)]/2
   + Fv·(v+ − v−)/2 + J_eff·(a+ − a−)/2 + 方向奇位置项

S = (τ+ + τ−)/2
  ≈ 同一 Fc/Fv/J_eff 对应的半和运动项
   + 平滑角度趋势 + 方向偶位置项
```

同姿态下共同重力和方向偶位置项会在 D 中消去；实际其余关节仍有小位置差，因此是近似抵消，不是物理重力校验。S 的三次角度趋势仅作描述，不将其称为辨识出的重力模型。所有力矩和系数仍为协议尺度，未从中减去 Nm 制 URDF 重力，`J_eff` 不标为 kg·m²。

比较 velocity（Fc/Fv）、inertia（再加 J_eff）、spatial（再加方向奇/偶角周期项）三个嵌套模型。周期只用训练日志在 .03～.06 rad 搜索；验证不调整任何系数、相位、周期或求导窗口。模型记录源码和输入哈希，拒绝同源数据改名验证，且不能经现有补偿入口加载。

负 Fv 不证明机械臂产生“负摩擦”。它表示当前平滑库仑+线性黏性模型及现有数据无法支持所需物理解释；速度相关非线性、测量/控制耦合、温度变化等仍需区分，不能仅靠更小残差选择一种成因。

## 导数窗口敏感性

额外用 .16/.24 s 窗口离线重算 J1/J2，仅检查敏感性；不改变实机控制、原 Method D 门限，也不挑选最有利窗口发布参数。

| 轴 | .16 / .20 / .24 s 的 J_eff | 三个窗口的空间模型验证 RMSE |
|---|---|---|
| J1 | .373 / .468 / .555 | .0993 / .0996 / .1001 |
| J2 | 1.328 / 1.585 / 1.803 | .3292 / .3339 / .3275 |

预测误差相近，J_eff 却随导数窗口明显变化；Fv 删除往返变号在三个窗口都存在。这进一步说明各项可能共同吸收了滤波后的周期运动和误差，不能把预测有效等同于已测得真实惯量/摩擦。

J1/J2 spatial 的训练周期分别约 .049875/.050125 rad，延续此前的位置相关证据；J3 .04925、J4 .044125 是在当前耦合动态模型下选出的诊断周期，不能替代物理周期测量。

## 下一步的采集设计依据

本轮到此不部署任何参数。下一轮不能只增加相同恒速往返次数：

1. 优先补 J2/J1 在同样配置下的多速度独立重复，保留完整温度/载荷记录，并记录实际加减速配置。J1 还需覆盖至少 .06 rad/s 的速度跨度。
2. 为惯性提供独立激励：在同一角区间、同一速度水平，安排不同且非对称的加减速时长，使相同角度下出现不同加速度。完全对称的正反轨迹中 a+≈a−，惯性会在 D 中同时抵消；仅改变对称斜坡时长并不能保证分离。需要先做轨迹预览和设计矩阵检查，再做实机采集。
3. 当前配对分支**仅取恒速指令阶段中的实际波动**，未使用指令加减速段。新实验须先扩展完整运动段的配对及覆盖检查，并保存 ramp-up/down 元数据，否则采到独立斜坡激励也不会进入本模型。
4. 对 J3 检查速度相关非线性及方向/温度的重复性；当前负 Fv 不直接剪成零，也不直接增加补偿。J4 需要多档速度与独立加速度激励后才能评价动态参数。
5. 最后补齐已知质量/力臂的物理力矩校验，才讨论 Nm 参数与低比例补偿干预。
