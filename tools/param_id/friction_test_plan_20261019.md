# J1～J4 摩擦辨识下一轮测试方案

状态：已完成阶段一均值处理初检及阶段二J2 A–B–A实机对照。A1/A2平均配对量相差约20.2%，按方案停止阶段三扩采；速度反馈/阻尼项成为优先复核线索，见[实测报告](gain_aba_review_20261019.md)。目标是用最少的对照，决定当前系统适合哪条辨识路径，并量化控制、反馈与姿态/温度对结果的影响。当前以 J2 为代表轴先跑通流程，再推广 J1/J3/J4；J6 继续暂缓。

## 已知证据与边界

- 当前 NPZ 与保存的原始 CAN payload 按当前解码公式一致；主机接收后读取延迟没有解释现有大幅波动。它们不替代固件语义和物理力矩标定。
- J1/J4 的位置相关分量已有跨速度/换起点证据，不重复整套证明。
- J2 位置保持时反馈力矩仍有明显快变化；没有支持统一平移时间戳的强证据。
- 两次 J2 同路径的配对力矩半差均值 .36763/.35620，比逐点值更重复；这些值不是已分离的 Fc，也不是已标定 Nm。
- 运动导数来自编码器，没有独立轴运动参考。最终仍可能无法仅用现有反馈区分真实转矩纹波与编码器/内部估计误差。

因此测试通过的目标是得到对合理处理、控制配置和独立运行都足够稳定的辨识结果，而不是要求原始曲线没有波动。

## 固定条件

1. 每个实机运行均 **折叠→HOME→实验→HOME→折叠确认→失能**，继续使用现有保护及退出逻辑。
2. J2 固定 HOME=[0,1.2,1,0,0,0]，正向行程 .55 rad；夹爪、载荷及线缆布置固定。J5/J6保持姿态。
3. 每次只改变一个因素；增益对照时不同时改变速度、斜坡、处理规则或载荷。
4. 记录实际六轴姿态、温度、接近方向、全部增益、轨迹和原始帧。比较相同到位顺序的保持段；不把初次 HOME 与反向返回 HOME 当作相同摩擦历史。
5. 分短轮采集并折叠失能冷却，避免长时间保持造成 J3 温升。增益对照尽量匹配初始温度（建议 J2差≤3°C，其他保持轴也记录）；这个匹配标准是本轮设计约束，不是厂家性能指标。

## 阶段一：先固定分析方法，新增动作0次

使用现有多速度、互换斜坡与长保持日志，建立一个明确的处理分支：

- 主数据：同位置正反配对，匹配实际其他轴姿态，使用相同角区间和位置权重。
- 同时保留两类帧及各自诊断结果，不仅凭曲线更平滑选择帧类型。
- 对配对目标 D 和所有回归列（速度、平滑库仑特征、加速度、位置正弦/余弦）使用同一个线性位置域处理；先构造非线性特征，再处理这些特征。禁止只平滑力矩而不处理模型列。
- 建议预先固定 .004 rad 高斯标准差为主处理，.002/.006 rad仅做敏感性检查；端点剔除至少3倍标准差，避免边界处理影响。该范围是待验证方案，不是已证明最优的滤波器。
- 原位置求导窗口保持 .20 s；保留 .16/.24 s 敏感性检查。附加一致处理不能消除原导数偏差和编码器误差。
- 在位置配对并构造模型后应用相同线性算子，尽量保持配对方程的一致性；不在不同速度的时间窗口中直接假定重力恰好抵消。
- 每次完整往返为一个独立统计单位，报告均值、覆盖率、往返间离散度、删除一次往返后的系数范围；相邻bin不当作独立重复。

保留两条路径：原 Method D 仅使用原门限认可的稳态数据；完整运动动态分支使用显式惯性/位置项，单独验证，不能冒充 Method D通过。

**继续条件**：处理方案在独立旧日志中改善重复性，同时主要结果对小范围处理变化稳定。若只有某个滤波参数能给出“好系数”，先解决估计方法，不增加实机次数。方案与阈值在新增验证数据前冻结，旧日志只用于方法开发，不能再称为前瞻盲测。

## 阶段二：一次 A–B–A 增益对照，最多3次运行

目的：判断较大的反馈力矩快变化是否随阻尼设置可重复改变，并检查平均配对量是否也被控制配置显著改变。

| 设置 | J2 kp/kd | 其他条件 |
|---|---|---|
| A1 | 150/20 | .10 rad/s；.8秒加速/2秒减速；一次往返；保持3秒 |
| B | 150/10 | 与A1相同 |
| A2 | 150/20 | 与A1相同，用来检查时间/温度漂移 |

每次独立启动和折叠失能，温度匹配后再进行下一次。沿用已试验过的增益，不在同一动作中突然切换参数。

比较：保持与运动的分帧力矩残差功率、位置跟踪及配对覆盖、带宽一致处理后的往返均值、实际姿态与温度。先看 A1/A2 是否重复，再解释 B 的差异。

决策：

- B 的快变化减少且 A2 恢复，支持“阻尼/闭环设置与波动有关”；仍不能据此认定是控制器噪声的唯一来源或电机本体故障。
- 若平均配对量基本不变，说明主要影响可能在快变化分量，辨识可以侧重整次往返统计。
- 若平均量也明显变化，先查实际轨迹、配对姿态和接近历史；控制依赖未分开前，不输出固有摩擦参数。
- 若降低D损害运动覆盖或稳态条件，不以“力矩更平滑”为唯一理由选它。综合重复性和可用运动数据选定一套增益，之后固定。
- 若 A1/A2 已明显不一致，本轮对照不支持增益因果判断，先解决漂移/重复性，停止多速度扩采。

## 阶段三：两端速度筛查，先4次往返

固定选定增益和处理方案，先测试 .06/.12 rad/s，各2次往返，交错顺序分短轮完成。这一步优先回答“速度变化引起的平均量变化，能否与重复波动分开”，暂不追求一次拟合出全部参数。

主要观察：相同角区间、相同权重下的配对量；惯性项/位置项占比；速度两端的差异与同速度重复离散度。两次重复只作筛查，不据此给可靠置信区间。

决策：

- 同速度可重复、跨速度存在可分辨差异：进入三档正式训练。
- 同速度可重复、跨速度差异小于重复波动：可以继续评估“该速度范围的平均摩擦力矩”，但 Fv 暂不可辨识；不强行拟合黏性斜率。
- 同速度也不重复：停止增加速度档，回查控制、姿态、温度和反馈；不把更多点数当作更好辨识。
- 若力矩随速度下降，检验库仑+线性黏性模型是否适合；保留负斜率证据，不剪为0，也不立即认定真实黏性为负。需要新模型时重新冻结方案并使用新的独立验证数据。

## 阶段四：正式训练与独立验证

仅在前面筛查通过后补齐 .06/.09/.12 rad/s，每档至少3次往返。阶段三可用数据计入训练，总训练目标9次往返，而不是重新全部采集。

冻结模型、周期、处理、窗口和剔除规则后，新开独立运行改变速度顺序，三档各一次往返。按温升分批，预计新增3次验证往返。它只验证这三档及当前姿态/载荷范围，不扩大成任意运动能力证明。

建议先采用以下工程筛查标准，实施前冻结；它们不是厂家指标或物理正确性的证明：

- 同速度往返均值的变异系数≤10%（均值接近0时另设基于实测噪声的绝对误差预算，不能除以近零均值）。
- 冻结处理后，独立运行同速度均值与训练均值偏差≤10%；同时报告绝对误差，不只报百分比。
- 滤波/求导窗口敏感性下 Fc、Fv、J_eff 保持可接受稳定性；Fv 不因删除一次往返而变号。Fv 接近0且无法确定时，报告“未分辨”，不声称精确识别。
- 动态模型若仍有负系数、明显参数互相补偿或强窗口敏感性，判为参数解释未通过，即使预测误差下降也不部署。
- 固定处理后的残差、方向差异和每个速度结果都须审查，避免用总平均掩盖某一方向失败。

## 阶段五：推广与物理校验

J2 流程通过后，J1先检验该流程能否在重力项近零的轴上重复；随后 J3、J4逐轴执行短筛查。滤波和门限以冻结方案为基线，各型号如需不同设置须单独验证，不能默认 RS06与RS00反馈特性相同。

物理力矩校验并行准备：已知质量/有效力臂、安装姿态与安全固定条件齐备后，检查力矩尺度、符号与偏置。当前没有校验条件，阶段一至四可以输出协议尺度诊断，但不能把结果发布为已标定 Nm 摩擦参数。没有独立运动/力矩参考时，对编码器误差、电机换相或机械传动的故障归因保留边界。

## 最短执行路线与停止原则

顺序：**已有日志固定方法 → J2 A–B–A对照 → 两端速度筛查 → 补齐训练 → 独立验证 → 推广与物理校验**。

下一次实机的目标首先是决定哪套控制/处理能给出可重复的配对量，而不是同时完成四轴。前一阶段失败就停止扩采；不同时改增益、轨迹、滤波和模型；不重做已建立的位置周期证据；不无依据平移时间戳或直接更改驱动内部滤波。

背景证据：[力矩接收链路](torque_chain_review_20261019.md)、[非对称试采](asymmetric_excitation_review_20261019.md)、[动态参数稳定性](primary_joints_dynamic_review_20261019.md)。
