# J6 力矩校验准备（尚未实施）

用户确认目前没有已知质量载荷、已测力臂及固定夹具，因此本文件是待执行方案，不是标定记录。所有现有反馈继续保持 `protocol_nm_unverified`；不能据此生成 `verified=true` 参数。

## 已有证据的边界

- 之前的重力标定笔记使用 MIT PD 跟踪误差估算力矩，并假定 kp 的 N*m/rad 比例准确。它能检查模型一致性，不能替代独立的反馈力矩标定。
- 本轮只读核查中 `0x3041` Kt 寄存器返回 0，且旧调试地址中的 CAN_ID 也返回 0，与实际响应节点 6 不符。这些零值不能用作真实电机常数或校准状态结论。
- 厂家标称力矩常数也不替代实测：电流峰值/RMS、Iq 定义、减速比及输出端效率必须一致，不能直接将电流乘一个常数当作已验证关节力矩。

## 所需外部信息与装置

1. 可确认的质量及其不确定度，或经校准测力计/力矩传感器。
2. 相对 J6 轴线的位置矢量、力的方向及有效力臂，并给出测量不确定度。
3. 有额定承载能力、不会滑移的固定夹具；载荷和线缆布置单独记录为新的 load-id。
4. 安装后的运动范围与接触检查。安装载荷后不能直接复用空载实验的行程或增益假设。

J6 的外加重力矩应按以下式子计算，而不是一概使用质量 × 手臂总长度：

```text
tau_external = axis_world · (r_world × [mass * gravity_world])
```

其中 r 是从 J6 轴线上参考点指向载荷质心的矢量。载荷沿轴线同轴安装时，即使重量增加，也可能几乎没有绕 J6 的力矩，不能用于有效校验。

基于当前 URDF、HOME=[0,1.2,1,0,0,0] 的离线运动学，J6 世界轴向约为 [-0.9801, 0, 0.1987]，接近水平；重力负载理论上可以产生绕轴力矩，但必须通过明确的偏心力臂。实际安装方向、零位和质心仍须测量确认。

## 采集设计

- 先记录无外载基线，再以相同姿态记录已知外载。每组都保存原始 CAN 时间戳、q、反馈力矩、目标和驱动状态，不用主机 PD 误差替代反馈力矩。
- 多个正/负外力矩水平，重复安装/卸载，并从正反方向接近目标姿态，评估静摩擦和迟滞影响。确认位置窗口稳定后再统计；不要求有噪声的瞬时驱动速度恰为零。
- 所有测试应无连杆、桌面或夹具接触；外力矩需要可分辨于静摩擦/噪声，同时低于夹具和实验力矩上限。数值由实际装置决定，本方案不虚构砝码或力臂。
- 留出独立载荷水平或完整重复运行验证，检查残差是否随角度、方向、温度和载荷变化。

## 能识别什么

差分关系 `delta_tau_external = scale * delta_tau_protocol` 可以检验比例和符号，并抵消部分常量重力及零偏，但**不能单独识别绝对零偏**。零偏需要额外可确认的零力矩基准，或独立力矩传感器及完整力矩平衡；不能仅通过 URDF 重力拟合宣称零偏已标定。

拟合应报告比例、符号、零偏是否实际可辨识、测量不确定度、重复性及独立验证误差。若零偏未确认，报告必须保留这一限制，不直接形成完整补偿参数。
